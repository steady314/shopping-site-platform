# Shopping Site

A responsive e-commerce frontend built with React and Vite.

## Features

- Product browsing
- Product search
- Category filtering
- Product details
- Shopping cart
- Quantity management
- Cart persistence with localStorage
- Checkout form
- Form validation
- Order success page
- API integration
- Loading and error states
- Responsive design
- Accessibility considerations

## Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- REST API
- localStorage
